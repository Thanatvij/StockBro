# StockBro (καιρός) — SPEC เฟส 1 (ชื่อเดิม Kairos)

## 1. คืออะไร
เว็บ/brief รายวันสำหรับ **นักลงทุนหุ้นสหรัฐฯ ชาวไทยที่ถือหุ้นรายตัวไม่กี่ตัว** (ผู้พัฒนา = Thanat และกลุ่มเพื่อน ไม่ใช่บริการสาธารณะ)
ตอบ 3 คำถามก่อนตลาดเปิด (ตลาดเมกาเปิด 21:30 น. เวลาไทย, 20:30 น. ช่วง daylight saving):
1. ข่าวอะไรที่กระทบ **หุ้นที่ฉันถือ** และข่าวนั้น **จริง / ใหม่ / ตลาดรู้ไปแล้วหรือยัง**
2. ราคาตอนนี้อยู่ตรงไหนเทียบแนวรับ-แนวต้าน
3. ที่ผ่านมาแนวรับที่ระบบคำนวณ **แม่นแค่ไหนจริง** (accuracy tracker)

ที่มาของโปรเจกต์: Thanat ซื้อ SPCX จากข่าว TikTok เรื่อง "รับจรวดด้วยแขนกล" ซึ่งจริงแต่เป็นข่าวเก่าเกือบ 2 ปีและราคา price-in ไปแล้ว
บทเรียน: ปัญหาไม่ใช่ข่าวปลอม แต่คือ **ข่าวจริงที่เก่า/ไม่ได้กระทบราคาแล้ว** → ระบบต้องบอกอายุข่าว แหล่ง และการเคลื่อนไหวของราคา

## 2. หลักการที่ห้ามละเมิด (สืบจาก ARGUS)
1. ตัวเลขทุกตัว (แนวรับ แนวต้าน คะแนนข่าว สถิติ) มาจาก **กฎที่ตรวจสอบย้อนได้** ไม่ใช่ LLM เฟส 1 ไม่เรียก LLM เลย
2. ข่าวแสดงพร้อม **แหล่ง เวลา และอายุ** ข่าวเก่า > 7 วันติดป้าย; filings จาก SEC แยกเป็น "แหล่งทางการ"
3. ทิศทางข่าว (บวก/ลบ) ตัดสินจากคำในพาดหัวและแสดงว่า "จากพาดหัว" ไม่ใช่ความเห็นของระบบ
4. **ไม่แนะนำซื้อ/ขาย** ใช้ถ้อยคำ "โซนติดตาม", "จุดตัดขาดทุนอ้างอิง", "ราคาห่างแนวรับ X%" แสดง disclaimer ทุกหน้า
5. ไม่แต่งตัวเลข ถ้าข้อมูลไม่พอให้บอกว่า "ยังสรุปไม่ได้"
6. ค่าพารามิเตอร์ทุกตัวเป็น **ค่าตั้งต้นที่ยังไม่พิสูจน์** ปรับจากผล backtest/forward-test เท่านั้น
7. ข้อมูลพอร์ตเป็นข้อมูลการเงินส่วนบุคคล: ห้าม commit พอร์ตเพื่อนขึ้น repo สาธารณะ (ดู DECISIONS D-05)

## 4. การคำนวณ
- **Pivot (classic)** จากแท่งล่าสุด: P=(H+L+C)/3, R1=2P−L, S1=2P−H, R2=P+(H−L), S2=P−(H−L)
- **ระดับอื่น**: MA20/50/200, สูง/ต่ำสุด 52 สัปดาห์ → รวมเป็นรายการ แยกรับ (ต่ำกว่าราคา)/ต้าน (สูงกว่าราคา)
- **เทรนด์**: ราคา>MA50>MA200 ขาขึ้น; ราคา<MA50<MA200 ขาลง; อื่นๆ ไซด์เวย์
- **โซนติดตาม**: แนวรับที่ใกล้ราคาที่สุด; stop อ้างอิง = แนวรับถัดลงไป −1% (ไม่มี → โซน −3%); เป้าแรก = แนวต้านใกล้สุด; R:R
- **คะแนนข่าว** = น้ำหนักหมวด (1–3) × ความสด (≤24ชม.=1.0, ≤48=0.7, ≤7วัน=0.3, เก่ากว่า=0.1) × (1+0.2×(จำนวนสำนักซ้ำ−1, สูงสุด 4))
- **จัดกลุ่มข่าวซ้ำ**: Jaccard ของคำในพาดหัว ≥ 0.5
- **คืนนี้ควรดู**: ใกล้แนวรับ ≤3%, ราคาขยับ ≥3%, 8-K ใหม่ ≤3 วัน, ข่าวคะแนน ≥2.5, พอร์ตกระจุกตัว ≥35% — เรียงตาม (ความสำคัญ + สัดส่วนในพอร์ต)

## 5. Accuracy Tracker (จุดต่างของระบบ)
**นิยาม "แม่น"** (ค่าตั้งต้น horizon=5 วัน, target=+2%, stop=−2%):
- วัน i ใช้ S1 จากแท่งวัน i−1; "แตะ" = low_i ≤ S1
- หลังแตะ: `bounce` = high ถึง S1×1.02 ก่อน low ถึง S1×0.98; `broke` = กลับกัน (วันเดียวกันถึงทั้งคู่ = broke); `none` = ไม่ถึงทั้งคู่ใน 5 วัน
- **Baseline**: ระดับสุ่มห่างจากราคาปิดวันก่อนเท่ากับระยะมัธยฐานของ S1 ใช้กติกาเดียวกัน — ถ้า S1 ไม่ชนะ baseline แปลว่าสูตรไม่ให้ข้อมูลเพิ่ม (แสดงเป็น edge เป็นจุด %)
- ตัวอย่างน้อยกว่า 20 ครั้ง → "สรุปไม่ได้"

**สองโหมด**
1. *Backtest* ย้อนหลังจากราคา 2 ปี (ทำได้ทันที)
2. *Forward-test*: ทุกวันที่รันบันทึกสัญญาณลงตาราง `signals` (SQLite → Postgres/Neon เฟส 2) แล้วตัดสินผลหลังผ่าน 5 วันทำการ **ต้องเริ่มเก็บตั้งแต่วันแรก** ย้อนไปเก็บทีหลังไม่ได้ ข้อมูล `--offline` ไม่ถูกบันทึก
